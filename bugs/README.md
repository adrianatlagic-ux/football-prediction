# Fehlerberichte

Ein Bericht je Fehler, Dateiname `JJJJ-MM-TT-kurzer-titel.md` (Datum der
ersten Meldung). Jeder Bericht hat oben einen Status:

- **offen**: Ursache nicht gesichert oder nicht behoben
- **Ursache gefunden**: belegt, Korrektur steht aus
- **behoben**: mit Commit und, wo möglich, Test
- **nicht bestätigt**: gemeldet, aber durch die vorhandenen Daten nicht belegt

Belege stehen im Bericht selbst (Log-Zeilen, Zahlen, Befehle), damit er ohne
Zugang zum Server nachvollziehbar bleibt. Vermutungen werden als solche
gekennzeichnet.
